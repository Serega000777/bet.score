# База данных

PostgreSQL является источником истины. Начальная миграция содержит минимальный независимый каркас identity и sports catalog; остальные таблицы добавляются только вместе с подтверждёнными сценариями и тестами миграций.

Правила:

- UUID генерируются PostgreSQL;
- время хранится в `timestamptz` в UTC;
- внешние provider id не используются как первичные ключи;
- миграции неизменяемы после применения в общем окружении;
- destructive migration требует двухфазного выпуска.

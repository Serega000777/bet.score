# Открытые вопросы

## P-001. Первый рынок

Варианты: Россия/СНГ, Европа, глобальный англоязычный рынок. Рекомендация: выбрать один рынок после юридической оценки, поскольку это определяет локализацию, платежи и допустимое представление коэффициентов.

## P-002. Первый вид спорта

Варианты: футбол, хоккей, мультиспорт. Рекомендация: начать с футбола и ограниченного набора соревнований для контроля качества данных.

## D-001. Поставщик спортивных данных

Нужно сравнить покрытие, LIVE-задержку, историческую глубину, SLA, лицензию и стоимость. До решения запрещено связывать доменную модель со схемой конкретного API.

## L-001. Юридическая классификация

Требуется заключение по целевым юрисдикциям: дисклеймеры, возрастные ограничения, правила рекламы и допустимость отображения коэффициентов.

## B-001. Биллинг

Нужно выбрать валюты, платёжного провайдера, модель trial и правила возвратов после определения рынка.

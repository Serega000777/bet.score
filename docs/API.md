# API bet.score

## Версионирование

Публичные маршруты начинаются с `/api/v1`. Несовместимые изменения выпускаются в новой major-версии. Ошибки используют единый объект с машинным `code`, сообщением и correlation id.

## Текущий контракт

`GET /api/v1/health` возвращает состояние процесса и версию API. Endpoint не проверяет глубокую готовность зависимостей; readiness будет добавлен вместе с адаптерами БД и Redis.

## Будущие группы

- `/auth` — сессии и внешние провайдеры;
- `/sports`, `/competitions`, `/events` — каталог;
- `/events/{id}/analysis` — объяснимый анализ;
- `/events/{id}/news` — связанные новости;
- `/subscriptions` — доступ и биллинг;
- `/live` — WebSocket handshake и протокол событий.

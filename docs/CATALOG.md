# Модуль каталога матчей

## Назначение

Каталог предоставляет каноническую основу события для web, Telegram, LIVE, новостей и AI-анализа. Он не зависит от формата конкретного поставщика спортивных данных.

## Инварианты

- у матча ровно два участника;
- роли `home` и `away` уникальны в рамках события;
- счёт либо отсутствует, либо является неотрицательным целым числом;
- время хранится с часовым поясом и передаётся в ISO 8601;
- публичные идентификаторы являются UUID bet.score, а не внешними provider id.

## Слои

1. `domain/catalog.py` определяет событие, участника и статусы.
2. `application/catalog.py` задаёт порт репозитория и сценарии чтения.
3. `infrastructure/catalog_repository.py` реализует порт через SQLAlchemy.
4. `presentation/api/routes/events.py` публикует версионированный REST-контракт.
5. Web-клиент использует только публичный API.

## Демонстрационные данные

Seed нужен для локальной разработки и проверки вертикального пути. Он явно помечен как демонстрационный и не смешивается с ingestion. После выбора поставщика данные будут поступать через отдельный адаптер нормализации с идемпотентным сопоставлением внешних и канонических идентификаторов.
